# Streaming Detail Card Maker

브라우저에서 배경 이미지와 제목 로고를 업로드하고, 스트리밍 서비스 상세 화면 느낌의 카드를 만든 뒤 PNG로 저장하는 정적 웹앱입니다.

## 기능
- 배경 이미지 업로드
- 제목 로고 이미지 업로드 / 제거
- 배경 위치 X/Y, 확대, 어둡기, 블러 조절
- 제목 로고 크기 조절
- 연도, 러닝타임, 화질, 추천 문구, 줄거리, 출연, 장르, 작품 특징 입력
- 4:3 / 16:9 / 4:5 / 904:739 비율 선택
- PNG 저장
- 서버 업로드 없이 브라우저 내부에서 이미지 처리

## GitHub Pages 배포
1. 새 GitHub 저장소를 만듭니다.
2. 이 폴더 안의 `index.html`, `style.css`, `script.js`를 저장소 루트에 업로드합니다.
3. GitHub 저장소에서 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch** 선택 후 `main` / `/ (root)`를 지정합니다.
5. 잠시 기다리면 GitHub Pages 주소가 생성됩니다.

## 참고
PNG 저장에는 CDN의 `html2canvas`가 사용되므로 인터넷 연결이 필요합니다.
Google Fonts가 로드되지 않아도 시스템 폰트로 정상 작동합니다.

브랜드 로고나 실제 서비스 UI 에셋은 포함하지 않았습니다. 개인용 커스텀 카드 제작용으로 사용하세요.
