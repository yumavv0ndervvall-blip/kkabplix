# Streaming Card Maker v3

이번 버전은 CSS와 JavaScript를 전부 `index.html` 안에 넣은 단일 파일 버전이야.
GitHub에서 기존 `index.html`만 이 파일로 교체하면 돼. 기존 `style.css`, `script.js`는 남아 있어도 이 버전에서는 사용하지 않아.

수정 사항:
- 실시간 미리보기 로직 전체 재작성
- 텍스트 출력 오류 수정
- 로고/재생 버튼 기본 위치 하향
- 로고+버튼 Y 위치 슬라이더 추가
- 캐치프레이즈 Y 위치 슬라이더 추가
- 연령 등급 및 하단 배지 편집
- 줄거리 5줄까지 표시
- 오른쪽 의미 없는 원형 버튼 / 시청자 추천 제거
- 프리셋 저장/불러오기/삭제
