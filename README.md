# Streaming Card Maker

넷플릭스풍 상세 페이지 이미지를 브라우저에서 바로 만들 수 있는 정적 웹앱이야.

## 포함 기능
- 배경 이미지 업로드
- 제목 로고 이미지 업로드
- 로고 / 배경 위치 및 크기 조절
- 연도 / 러닝타임 / 화질 / 연령 등급 편집
- 하단 배지 / 로고 텍스트 커스텀
- 줄거리 / 출연 / 장르 / 특징 편집
- 프리셋 저장 / 불러오기 / 삭제
- PNG 저장

## 사용 방법
1. 저장소 루트에 `index.html`, `style.css`, `script.js`를 업로드
2. GitHub Pages를 `main` / `root`로 설정
3. 사이트에 접속해서 이미지와 텍스트를 넣고 PNG 저장

## 프리셋
- 프리셋은 브라우저 `localStorage`에 저장돼.
- 이미지까지 같이 저장하려다 용량이 넘치면 텍스트 / 설정만 저장하도록 처리했어.
