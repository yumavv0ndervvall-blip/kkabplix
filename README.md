# Streaming Card Maker v4

넷플릭스풍 상세 화면 이미지를 만드는 단일 HTML 웹앱.

## v4 변경점
- 로고/재생/플러스/하트 묶음 기본 위치 하향 조정
- 관람등급 ALL / 12 / 15 / 18 선택 UI + 등급별 색상
- 줄거리 영역과 오른쪽 정보 영역이 겹치지 않도록 폭/위치 재조정
- 캐치프레이즈 글자 크기 확대
- 장르 / 작품 특징 키워드 선택 팝업 추가
- 키워드 검색, 다중 선택, 선택 해제, 직접 키워드 추가 지원
- 프리셋 저장/불러오기/삭제 유지
- PNG 저장 유지

## GitHub Pages 업데이트
기존 저장소의 `index.html`만 이 버전의 `index.html`로 교체하면 됨.
커밋 후 사이트에서 Ctrl+F5로 강력 새로고침 권장.
